OPCIÓN 1: GITHUB PAGES (RECOMENDADO - GRATIS Y FÁCIL)
════════════════════════════════════════════════════════════════════════════════

1. Crear cuenta en GitHub (si no tienes): https://github.com/signup

2. Crear nuevo repositorio:
   - Nombre: jatopabus
   - Descripción: Jatopa Bus - Transporte Público CDE
   - Público (para Pages gratis)
   - Inicializar con README

3. Clonar el repositorio:
   git clone https://github.com/TU_USUARIO/jatopabus.git
   cd jatopabus

4. Copiar archivos de la app:
   - bus.html
   - index.html
   - README.md
   - manifest.json
   - sw.js
   - .gitignore

5. Commit y push:
   git add .
   git commit -m "Jatopa Bus App - Primera versión"
   git push

6. Habilitar GitHub Pages:
   - Ve a: Settings > Pages
   - Source: main branch
   - Save
   - Espera 1-2 minutos

7. Acceder en:
   https://TU_USUARIO.github.io/jatopabus/


OPCIÓN 2: SERVIDOR LOCAL (RED WIFI)
════════════════════════════════════════════════════════════════════════════════

Requisito: Python 3 instalado en tu PC

1. Abre PowerShell o Terminal

2. Navega a la carpeta:
   cd c:\Users\TERCERO-B18\Documents\jatopabus

3. Inicia el servidor:
   python -m http.server 8000

4. Deberías ver: Serving HTTP on 0.0.0.0 port 8000

5. Obtén tu IP local:
   - Abre PowerShell
   - Escribe: ipconfig
   - Busca "IPv4 Address" (ej: 192.168.1.100)

6. Desde otro dispositivo en la misma WiFi:
   http://192.168.1.100:8000/

SOLUCIÓN DE PROBLEMAS
════════════════════════════════════════════════════════════════════════════════

❌ "CORS Error" en consola:
   → Los mapas y recursos externos a veces tienen restricciones
   → Solución: Usar HTTPS (GitHub Pages lo proporciona automáticamente)

❌ Geolocalización no funciona:
   → Necesita HTTPS y permiso del usuario
   → Algunos navegadores necesitan "Seguro" (lock icon)
   → GitHub Pages es seguro automáticamente

❌ Mapa no carga:
   → Verifica conexión a internet
   → Los mapas necesitan que Leaflet y CartoDB estén disponibles
   → Espera 10 segundos y recarga

❌ App se ve rara en móvil:
   → Limpia cache: Menú > Historial > Borrar datos de navegación
   → O: Abre en navegación incógnita
